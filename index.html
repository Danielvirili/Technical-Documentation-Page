Introducción a HTML

HTML es el lenguaje estándar para crear páginas web.

Permite estructurar contenido mediante etiquetas.

<h1>Hola Mundo</h1>

Los navegadores interpretan HTML para mostrar contenido visual.

Estructura Básica

Todo documento HTML tiene una estructura principal.

Normalmente comienza con la declaración DOCTYPE.

<!DOCTYPE html>

Dentro de html encontramos head y body.

<body>Contenido</body>
Etiquetas Comunes

Existen muchas etiquetas para distintos propósitos.

Los encabezados van desde h1 hasta h6.

<p>Texto de ejemplo</p>

También podemos usar imágenes, tablas y formularios.

Buenas Practicas

Usa nombres descriptivos para tus elementos.

Mantén una indentación consistente.

<section>Contenido</section>

Escribe código limpio y fácil de leer.
